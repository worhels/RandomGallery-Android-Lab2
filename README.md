# Випадкова галерея

Навчальний Android-застосунок для обов'язкового завдання лабораторної роботи №2 «Програмні компоненти Android» з дисципліни «Програмування мобільних пристроїв».

## Функції

- Завантаження фотографій із Picsum Photos за допомогою наданої бібліотеки `randomgallery-client-2.0.jar`.
- Галерея мініатюр із назвами, екран перегляду зображення, стан порожньої галереї та індикатор синхронізації.
- Збереження фотографій у внутрішньому сховищі застосунку та метаданих у `SharedPreferences`; дані залишаються після перезапуску.
- Ручна синхронізація через `JobScheduler` і `JobService` з обмеженням `NETWORK_TYPE_UNMETERED`.
- Спостерігач `SyncState.Observer` передає стани та прогрес інтерфейсу в головний потік.
- Перевірка оновлень через `ActionsHandlerService`, запит на оновлення після перезапуску через `BootReceiver` і системні сповіщення з діями підтвердження, скасування та закриття.
- Адаптивні фрагменти та темна тема з бірюзовими акцентами.

## Архітектура

`GalleryApplication` створює `RandomGalleryClient` із реальною `PicsumGallerySource` та `GalleryStorageImpl`. `GalleryStorageImpl` реалізує всі методи `GalleryStorage`, записує зображення атомарно у внутрішній каталог і зберігає індекс та timestamp у `SharedPreferences`.

`GalleryFragment` показує локальну галерею та спостерігає за `SyncState`. Запит на оновлення планується через `SyncService`, який працює як `JobService`; бібліотечний `ProgressListener` оновлює Observer та системне сповіщення. `DetailsFragment` відкриває повнорозмірне фото. `MainActivity` керує переходами та системною кнопкою Back.

`ActionsHandlerService` перевіряє наявність оновлення. Якщо воно є, `NotificationHelper` показує сповіщення з підтвердженням і скасуванням; `BootReceiver` відновлює запит на перевірку після перезавантаження пристрою. На Android 13+ дозвіл `POST_NOTIFICATIONS` запитується під час запуску оновлення. Всі `PendingIntent` використовують явні компоненти та immutable flags.

## Збірка і запуск

Відкрийте каталог `RandomGallery` в Android Studio, дочекайтеся синхронізації Gradle і запустіть конфігурацію `app` на пристрої або емуляторі. Для отримання зображень потрібен доступ до мережі; синхронізація JobScheduler запускається лише через Wi-Fi або інше з'єднання без тарифікації.

Перевірки з командного рядка у Windows:

```powershell
.\gradlew.bat assembleDebug
.\gradlew.bat testDebugUnitTest
.\gradlew.bat connectedDebugAndroidTest
```

Інструментальний тест `PicsumNetworkInstrumentedTest` звертається до справжнього Picsum Photos і пропускається, якщо в емулятора немає перевіреного інтернет-з'єднання. Він не замінює мережевий запит локальною заглушкою.

## Нотатки

- Наданий JAR має версію 2.0; його API перевірений через `javap`.
- `PicsumGallerySource` використовує URL-адреси та API, визначені бібліотекою; застарілий сервер із методички не використовується.
- Ідентифікатор галереї зберігається локально, щоб наступні синхронізації продовжували ту саму галерею.
